# Mainly Report ISTTS

Web pembuat Mainly Report: isi nama, NRP, dan project per bulan, lihat pratinjau surat A4, lalu unduh sebagai PDF.

## Fitur
- Tabel project per bulan (No, Nama, Jenis), disusun berurutan ke bawah. Nama bulan tercetak tebal dengan huruf kapital.
- Pratinjau surat langsung dan hitungan jumlah halaman PDF.
- Unggah kop surat ukuran A4 sebagai latar halaman, atau pakai logo dan kop teks.
- Unggah tanda tangan, pengaturan nomor surat, kota, tanggal, dan nama yang mengetahui.
- Isian tersimpan di browser (localStorage).

## Cara pakai
Buka `index.html` di browser (butuh internet untuk memuat font dan jsPDF dari CDN). Tombol **Unduh PDF** langsung menyimpan file.
